AppWithAI in ChatGPT

Check, repair and audit an EML model from inside a chat. Until the app is listed in OpenAI’s directory, you can add it to your own account in developer mode — about two minutes, private to you.

What you need

  • A ChatGPT plan that offers developer mode (Plus, Pro, Business or Enterprise; on Business and Enterprise an admin may have to allow it).
  • ChatGPT on the web. Set it up there once; the app then also appears in the mobile app on the same account.
  • This server address. It is public because ChatGPT’s servers call it, so localhost would not work:
https://appwithai-mcp.pramod-koshy.workers.dev/mcp

Names in ChatGPT’s settings move between releases. If a label below differs slightly, look for the closest one.

Add it

1

Turn on developer mode

Open ChatGPT in a browser, go to Settings → Apps (called Connectors in some versions), open Advanced settings and switch on Developer mode.

2

Create the app

Choose Create (or Add a custom app) and enter: Name AppWithAI; Description “Check, repair and audit AppWithAI EML models in ChatGPT without sending model contents to AppWithAI.”; MCP server URL the address above; Authentication None.

3

Confirm

Tick the box saying you understand a custom app is unverified, then Create. ChatGPT lists two tools: open_appwithai and get_eml_engine.

4

Open it in a new chat

Start a new chat, choose + → More (or the developer-mode menu), pick AppWithAI and send Open AppWithAI.

Using it

  1. Attach your .mmd file to the chat. If you only have the text, paste it into the chat and ask ChatGPT to save it as a .mmd file.
  2. Open AppWithAI. In the panel press Choose a file from this chat and pick the file.
  3. The panel shows the verdict, the 22-point audit and every problem with its line. Save the .mmd puts the repaired copy back into the chat.

Inside ChatGPT the panel has no file picker or paste box of its own: the model always comes from the chat. The standalone checker at /plugin/ keeps its own.

The prompts on Try It Yourself tell ChatGPT to open the panel by itself once your model is delivered, when this app is added.

Privacy

AppWithAI’s server never receives your model. Both tools take no input, the checker runs in your browser, and the panel may connect only to ChatGPT’s own file hosts. get_eml_engine prints the EML version and the SHA-256 of every file the panel runs, so you can compare them with the published checker and the files beside it. The details are in the privacy policy.

If something is wrong

What you seeWhat to do
No Developer mode switchYour plan or workspace does not offer it. Ask an admin, or use the chat-only route on Try It Yourself.
ChatGPT cannot reach the serverCheck the address ends in /mcp. Opened in a browser tab it answers with an error, which is fine; a timeout is not.
The panel opens but lists no fileAttach the .mmd to the chat first, then press Choose a file from this chat again.
A change on this site is not showingStart a new chat; ChatGPT caches the panel per conversation.

To remove it: Settings → Apps → AppWithAI → Delete.
