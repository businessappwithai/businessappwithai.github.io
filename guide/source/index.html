The published validators, carried inside pages

You almost certainly do not want this page. The validators are served as files, and fetching them directly is one line:

curl -sO https://www.appwithai.org/guide/check-model.mjs
node check-model.mjs <model>.mmd

This directory exists for one observed failure: a browsing or fetch layer that reads text/html but refuses application/javascript, and reports the module as inaccessible while the same host serves it pages without complaint. Each page below carries one file base64-encoded, with its SHA-256, so the bytes can be reconstructed and proved to be the published ones.

If your shell reaches no host at all, prefer check-model-standalone.mjs: one file, both modules and both runners inside it, nothing to reassemble.
