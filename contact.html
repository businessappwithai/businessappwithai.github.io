Frequently Asked Questions

Answers to common questions about AppWithAI.

Do I need technical expertise to use AppWithAI?

No. AppWithAI is designed for business analysts and domain experts. Describe your business process in plain English, and the AI pipeline handles all technical implementation. Technical users can also inspect and extend the generated code.

What if the AI does not understand my process correctly?

The mandatory Human-in-the-Loop review gate ensures you review the complete data model before any code is generated. You can modify, add, or remove any entity, attribute, or relationship in the visual ERD designer before approving.

Is AppWithAI truly open source?

Yes. AppWithAI is released under the Apache License 2.0 — one of the most permissive open source licenses available. You may use, modify, and distribute AppWithAI commercially without restriction. The full license text is available at apache.org/licenses/LICENSE-2.0.

Who owns the generated application code?

You own 100% of the generated code. There is no vendor lock-in. Generated applications are standard TypeScript — you can modify, extend, commercialize, and maintain them independently, with no obligations to AppWithAI.

Which AI providers are supported?

AppWithAI supports Anthropic Claude (primary), OpenAI-compatible endpoints, and any local model available via Ollama. You bring your own API key. Organizations with data sovereignty requirements can run entirely on local LLMs.

Can generated applications integrate with existing systems?

Yes. Generated applications expose standard RESTful JSON APIs for all entities, enabling integration with any modern enterprise system. The generated NestJS backend can be extended to support additional integration patterns.

What security and compliance features are included?

AppWithAI generates enterprise-grade security as standard: role-based access control, field-level security, row-level security, complete audit trails, and session management via Better-Auth.

What does the generated application technology stack look like?

Generated applications use TanStack Start (React 19+ with SSR) for the frontend, NestJS 10+ with Fastify for the backend API, Kysely for type-safe database access, and PostgreSQL for data persistence — with Playwright end-to-end tests and Docker configuration included.
